# 📊 Cobra Fee Analyzer - Feature Overview

## 🎯 Core Features

### 📈 Financial Analytics Dashboard
- **Real-time Fee Analysis**: Instant breakdown of all trading costs
- **P&L Tracking**: Net and gross profit/loss calculations
- **Symbol Performance**: Best and worst performing symbols by efficiency
- **Risk Assessment**: Automated identification of high-cost and loss positions

### 📊 Interactive Visualizations
- **Daily Fee Breakdown Chart**: Stacked bars showing expense fees + Gross P&L line
- **Interactive Pie Chart**: Drill-down capability from categories to symbols to dates
- **Color-coded Charts**: Consistent visual language across all visualizations

### 🔍 Advanced Filtering & Search
- **Date Range Filtering**: Filter transactions by specific dates or periods
- **Symbol Filtering**: Focus on specific ticker symbols
- **Transaction Type Filtering**: Filter by trade types (Overnight, Locate, Market Data, etc.)
- **Real-time Filtering**: Instant updates as you type

### 📤 Data Export & Integration
- **CSV Export**: Download filtered transaction data
- **Excel Export**: Export to .xlsx format with formatting
- **Filtered Exports**: Export only the data you're viewing
